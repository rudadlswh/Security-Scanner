# 게시용 복사본 확인 기록

2026-10-22 Windows에서 과거 실험/진단 자료를 포함하지 않은 게시용 복사본을 확인했다.

| 확인 | 결과 |
| --- | --- |
| Java 브리지 | JDK17·Gradle8.9, `--offline --no-daemon prepareProductRuntime` 빌드 성공 |
| 제품 단위·통합 테스트 | 포함된6개 Python 테스트 모듈에서90회 실행, 실패/오류0. 상속에 의한 중복 실행 포함 |
| 새 MCP STDIO | 24개 도구 노출, 잘못된 요청15개 거부, 조회3건 |
| MCP 프롬프트 | 4개 프롬프트, 조회5회, 잘못된 요청2개 거부 |
| 정적 게시 전 확인 | Python AST·JSON·TOML 구문 확인. 비밀키/일반 API 자격증명 패턴 미발견 |
| 실제 외부 실행 | 새 모델 생성·온라인 CVE 조회·Docker·실제 프로젝트 보안검사 없음 |

단위 테스트의 서버·모델·CVE 대역과 로컬 일회용 HTTP를 실제 보안 원인 검증으로 해석하지 않는다. 정적 자격증명 패턴 확인도 모든 민감정보 부재를 보증하지 않는다. 기존 개발 환경의202회/Java178개 기록은 이 게시본 검증과 별개이며 해당 원문은 공개하지 않는다.

이 기록은 같은 AI가 패키징하고 확인한 결과로 독립 검토가 아니다. 실제 응답·호환성·보안의 일반 정확도나 모든 격리 방어를 보증하지 않는다. 원본·과거 실행 기록과 닫힌 예산은 변경하지 않았다.
