# 게시용 복사본 확인 기록

## 2026-10-24 /6 게시본

`chogm`에 반영할 제품 코드·합성 테스트·문서를 별도 체크아웃에서 확인했다. 개발 원본의 로컬 결과·승인·설정은 복사하지 않았다.

| 확인 | 결과 |
| --- | --- |
| Java 브리지 | JDK17과 기존 캐시 JAR만 사용한 오프라인 빌드 성공. 입력9개·출력29개 해시 영수증 생성 |
| 포함된 Python 테스트 | 149회 통과, 고유132개+상속 중복17회, 실패/오류0 |
| 새 MCP STDIO | product-workflow/6·audit-ledger/2·security-remediation/17, 27도구/4프롬프트 |
| 요청 거부 | 기존15건+새 감사 도구3건=18건 거부 |
| 비동기 감사 검증 | 시작→DEFERRED→상태·보고서 조회. opt-in 없는 상태에서 네트워크/모델 호출0회 |
| 문서 | 27개 MCP 도구·4개 스킬 명령 목록, 공개 저장소 내 상대 링크 확인 |

초기 실행에서 오래된 Docker 대역 응답에 현재 네트워크/IPv6 검사 필드가 빠진 오류1건이 있었다. 대역 응답을 현재 계약에 맞춘 뒤149회 전체를 다시 통과했다. 실제 Docker·모델 생성·온라인 CVE·실제 프로젝트 보안 검사는 실행하지 않았다. 테스트의 임시 HTTP/TCP 서버·모델 대역·임시 서명 키를 실제 서비스/검토자 검증으로 세지 않는다.

149회는 이 게시용 모듈 구성의 결과다. 개발 원본의129회·과거202회 또는 Java178개 기록을 가져온 수치가 아니다. 빌드 산출물·영수증·로컬 로그는 Git에 포함하지 않는다. 등록 키 보유, 별도 모델 digest와 요청 분리는 실제 사람의 신원/미참여·오류 독립성·모델 의미 정확성의 증명이 아니다. 수집 파일·HTTP 경계·지원 sink 목록은 전체 공격 표면의 완전성을 보증하지 않는다.

## 2026-10-22 /3 게시본 당시 기록
